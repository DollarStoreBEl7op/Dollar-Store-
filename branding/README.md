# Dollar Store logo

`dollar-store-logo.png` is the user's original uploaded TMS / Dollar Store / Server & Exchange image, preserved without changes.

The horizontal WebP rearranges crops of that same badge and wordmark for desktop navigation. The compact WebP and `../favicon.png` use the badge from that image. No replacement artwork or generated lettering is used.

The shared Logo component uses the full upload on account, seller/admin and footer surfaces, the horizontal version in desktop headers, and the compact badge in small mobile headers. Product brand logos and the sword cursor are independent assets.
