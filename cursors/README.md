# Dollar Store cursor

`dollar-pixel-cursor.png` is derived only from the user-supplied `Glowing Pixel Diamond Sword with Electric Energy.png` in the user's Downloads folder.

The surrounding background was masked out along the sword silhouette. The original sword's pixels and colors were preserved, then reduced using nearest-neighbour sampling to a transparent 32 × 48 PNG. No substitute sword or generated illustration was used.

The CSS hotspot is at pixel 27, 1, on the blade tip. CSS loads this cursor only for devices matching `(hover: hover) and (pointer: fine)`. Buttons and links retain a pointer fallback; the rest of the page uses an automatic fallback. Editable text uses its standard text-selection cursor. Touch devices retain native cursor behavior.
